# enterprise-iam-lab
Hands-on Enterprise Identity and Access Management lab demonstrating Microsoft Entra ID, RBAC, Conditional Access, MFA, identity lifecycle management, and PowerShell automation.



## PowerShell Automation

Automated Microsoft Entra ID identity lifecycle management
using Microsoft Graph PowerShell.

### Joiner Automation

- Creates new Entra ID users
- Assigns department and job title
- Assigns users to department security groups

### Leaver Automation

- Disables user accounts
- Revokes active sessions
- Removes department security group membership
